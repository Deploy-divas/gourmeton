# GourmetOn - Landing Page de Delivery de Cozinha Italiana

Uma landing page interativa desenvolvida como projeto acadêmico de Desenvolvimento Web. O objetivo principal do projeto é apresentar o aplicativo de delivery **GourmetOn**, focado em culinária italiana, enquanto demonstra o uso prático de requisições assíncronas (Fetch API) e manipulação de arquivos JSON em uma interface construída com React e Vite.

## 🎯 Objetivo do Projeto

Desenvolver uma página de apresentação informativa para um app de delivery, integrando dados reais através de uma API pública de alimentos e aplicando conceitos modernos de estilização e componentização.

## 🛠️ Tecnologias Utilizadas

- **[React](https://reactjs.org/):** Biblioteca JavaScript para construção da interface de usuário baseada em componentes.
- **[Vite](https://vitejs.dev/):** Ferramenta de build super rápida que oferece um ambiente de desenvolvimento otimizado para React.
- **[Tailwind CSS](https://tailwindcss.com/):** Framework CSS _Utility-first_ utilizado para estilizar toda a aplicação de forma rápida e responsiva.
- **JavaScript (ES6+):** Utilizado para a lógica de negócio, especificamente trabalhando com **JSON** e a **Fetch API** para consumo de dados assíncronos.

## 📡 API Utilizada

Os dados dos pratos, categorias e imagens são consumidos da **[TheMealDB](https://www.themealdb.com/api.php)**, uma base de dados aberta de receitas de todo o mundo. Para manter o tema, foram utilizados os endpoints de filtro por categoria e por área (Pasta).

## 🚀 Como executar o projeto localmente

Para rodar este projeto na sua máquina, você precisará ter o [Node.js](https://nodejs.org/) instalado.

1. Clone o repositório:

   ```bash
   git clone https://github.com/Deploy-divas/gourmeton.git
   ```

2. Navegue até a pasta do projeto:

   ```bash
   cd gourmeton
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

5. Acesse no seu navegador o endereço local que aparecerá no terminal (geralmente `http://localhost:5173/`).
