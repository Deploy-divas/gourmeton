# GourmetOn — Integrante 1

Parte visual da Landing Page do GourmetOn.

## Responsabilidade

- React + Vite
- Tailwind CSS
- Header/Menu
- Hero Section
- Seção Apresentação
- Seção Funcionalidades
- Menu fixo
- Scroll suave
- Responsividade dessas seções

As seções de Depoimentos, Formulário de Contato, Rodapé e integração com API/Fetch/JSON ficam para os demais integrantes.

## Tecnologias

- React
- Vite
- Tailwind CSS
- Lucide React

## Instalação

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```
